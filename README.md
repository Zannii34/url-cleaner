# URL Cleaner

A Chrome extension that strips tracking parameters from URLs before you share them.

## Features

- Right-click any link → "Clean this URL"
- Alt+Shift+C to clean the current page
- Popup for pasting and cleaning any URL
- Removes 40+ tracking parameters (utm_*, fbclid, gclid, etc.)

## Install

1. Clone this repo
2. Open `chrome://extensions`
3. Enable Developer mode
4. Click "Load unpacked" and select this folder

## Tech Stack

- Vanilla JavaScript
- Chrome Extensions Manifest V3
