## Store Listing Title (max 45 chars)
URL Cleaner — Strip Tracking Parameters

## Short Description (max 132 chars)
Remove tracking parameters (utm_*, fbclid, gclid) from URLs before you share them. One click, cleaner links.

## Detailed Description

Stop sharing links with tracking junk.

URL Cleaner strips 40+ tracking parameters from URLs before you share them.

**Features:**
• Right-click any link → "Clean this URL"
• Keyboard shortcut: Alt+Shift+C for the current page
• Popup for pasting and cleaning any URL
• Removes utm_*, fbclid, gclid, mc_eid, and 35+ other tracking parameters
• Auto-copies cleaned URL to clipboard
• Works on Chrome, Edge, Brave (all Chromium browsers)

**Why use it?**
When you copy a URL from most websites, it includes tracking parameters that:
• Make URLs ugly and long
• Track you across the web
• Look unprofessional when shared

URL Cleaner fixes this in one click.

**Privacy:**
• No data collection
• No network requests
• Works entirely offline
• Open source: github.com/Zannii34/url-cleaner
